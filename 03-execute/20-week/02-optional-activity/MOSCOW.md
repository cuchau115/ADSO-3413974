# MOSCOW

## Must Have

Todo lo indispensable para cumplir el PRD.

- Login
- CRUD propietarios
- CRUD mascotas
- CRUD veterinarios
- Agenda de citas
- Registrar consulta
- Registrar diagnóstico
- Registrar tratamiento
- Registrar prescripción
- CRUD medicamentos
- CRUD lotes
- Reporte de citas sin consulta
- Validación de lote vencido
- JWT
- Contraseñas hasheadas


## Should Have

- Buscar propietarios
- Buscar mascotas
- Ordenar citas por fecha
- Filtros por veterinario
- Historial de tratamientos por mascota (obtenido mediante consultas, sin entidad aparte)
- Validaciones de formularios

## Could Have

- Fotos de mascotas
- Razas
- Especies

- Notificaciones de vencimiento de lotes

## Won't Have
- Pago de consultas
- Facturación

- Agenda en línea para clientes
- Aplicación móvil
- Portal para propietarios
